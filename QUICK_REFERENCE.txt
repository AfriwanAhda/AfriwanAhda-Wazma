ACTIVITIES AT A GLANCE
================================================================================

  Extends:        AppCompatActivity
  Layout:         main_activity.xml
  Purpose:        Display list of Quran Surahs
  Key Methods:
    - onCreate():          Initialize UI, load Surah list, set adapter
    - setListData():       Populate 37 Quran chapters (hardcoded)
    - onItemClick():       Launch PlayActivity with selected Surah
  Data:           37 Surah names with verse counts (in Indonesian)
  Navigation:     Launches PlayActivity via Intent with position + name

ACTIVITY 2: PlayActivity
  Extends:        AppCompatActivity
  Layout:         play_activity.xml
  Purpose:        Play Quran audio for selected Surah
  Key Methods:
    - initiate():         Setup UI components, extract Intent extras
    - setListener():      Register click listeners for play/pause/stop buttons
    - play(int):          Load and play audio file (HAS MEMORY LEAK)
    - pause():            Pause/Resume audio playback
    - stop():             Stop audio and reset to beginning
    - statePlay():        Enable/disable buttons during playback
    - stateAwal():        Reset button state to initial
  Audio File Logic:
    - index == 0:         plays a1.mp3
    - index 1-36:         plays a(index+77).mp3
  Controls:       Play (blue), Pause (blue), Stop (blue) buttons
