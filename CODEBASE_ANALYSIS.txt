2. Memory Leak in PlayActivity - Multiple MediaPlayer Instances
   Severity: HIGH
   Issue: Each time play() is called, a new MediaPlayer instance is created
          without properly releasing the previous one
   Details: Line 89 in PlayActivity.java creates new MediaPlayer with:
            mp = MediaPlayer.create(this, item);
            If play button is clicked multiple times, old instances are not 
            released, causing memory leaks
   Impact: App may crash or become unresponsive with repeated play attempts
   Fix: Release old MediaPlayer before creating new one:
        if (mp != null) { mp.release(); }
        mp = MediaPlayer.create(this, item);

3. No Error Handling for Missing Audio Files
   Severity: MEDIUM
   Issue: If an audio file (a1.mp3, a78.mp3, etc.) is missing from raw 
          resources, the app will crash without user-friendly error
   Details: getResources().getIdentifier() may return 0 if file not found,
            MediaPlayer.create() will fail silently or crash
   Impact: App crashes if any expected audio file is deleted/missing
   Fix: Add null check and error handling:

            Toast.makeText(..., "Audio file not found", Toast.LENGTH_SHORT).show();
            return;
        }
